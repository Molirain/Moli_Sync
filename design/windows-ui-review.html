选择数据存储位置

下载的图片、文件与断点续传缓存会保存在这里。程序文件与设置不会写入此目录。

C:\Users\ASUS\MoliSyncData
可用空间 186 GB·预计占用 < 100 MB（不含下载文件）
卸载时不会删除这个目录

卸载 MoliSync 只会移除程序、开机启动项与快捷方式。数据目录会保留，卸载界面会再次提示；如需彻底清理请手动删除 C:\Users\ASUS\MoliSyncData。

安装器：首次安装选择数据目录；覆盖升级沿用原目录，不再询问。

卸载 MoliSync

确定要卸载 MoliSync 吗？

将从这台电脑移除 MoliSync 程序、开机启动项、托盘图标与开始菜单快捷方式。

你的数据会被保留

卸载程序不会删除数据目录中的下载文件、图片与断点续传缓存。卸载完成后可手动删除该文件夹。

C:\Users\ASUS\MoliSyncData

卸载入口：Windows 设置 → 应用 → 已安装的应用 → MoliSync → 卸载。

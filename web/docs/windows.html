Windows client

The Windows client is a .NET 8 desktop app published for win-x64. It reads its certificate and private key from the Windows personal certificate store and connects to your HTTPS server.

Requirements

  • Windows 10 or 11 and the .NET 8 SDK.
  • NativeAOT publishing additionally requires the Visual C++ build tools.

Build and publish

cd client-windows
dotnet build MoliSync.Client.sln -c Release
dotnet test MoliSync.Client.sln -c Release
dotnet publish src/MoliSync.Client/MoliSync.Client.csproj -c Release -r win-x64 -o publish

Certificates

The client reads its certificate and private key from the Windows personal certificate store; nothing is exported into application files. If your server uses a private CA, import it once into Trusted Root Certification Authorities.

What you get

  • Text, image and file tabs with Range download resume.
  • Image thumbnails and a viewer.
  • P2P send and receive, online devices and LAN/VPN addresses.
  • Data-directory migration and autostart.

Run publish\MoliSync.Client.exe and enter your HTTPS server URL.

Shared behavior

The 15 MiB threshold, 49-byte frames, single-use session tickets and sender-only deletion are shared with Android. See shared client behavior or the full client-windows guide.

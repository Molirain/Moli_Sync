两个客户端共用同一套带版本的 HTTP/WebSocket 协议，并使用操作系统证书存储中的证书。服务器地址始终是 HTTPS。选择客户端查看构建与连接步骤。

Windows

.NET 8 桌面客户端，发布为 win-x64，从 Windows 个人证书存储读取密钥，并支持 NativeAOT。

构建并连接 Windows 客户端 →

Android

Kotlin 客户端，面向 Android 8.0 / API 26 及以上，通过 KeyChain 获取身份，并通过 MediaStore 归档下载。

构建并连接 Android 客户端 →

共同行为

  • 默认阈值 15 MiB；超过后只能 P2P。
  • 固定 49 字节 帧与一次性会话票据。
  • 只有发送者能删除记录。

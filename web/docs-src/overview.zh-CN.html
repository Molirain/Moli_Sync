MoliSync 是一个自托管控制面加两个客户端，用于在你掌控的设备之间搬运文字、图片与文件。身份来自客户端证书；传输优先尝试 LAN/VPN 直连，失败后回退到零落盘中继。

各部分负责什么

三个组件共用一套带版本的协议：

组件技术栈职责
控制面Go · Docker受信代理鉴权、设备注册表、WebSocket 在线状态、记录与 blob 存储。
Windows 客户端.NET 8 · Avalonia三栏云同步、读取系统证书、Range 下载、P2P 收发。
Android 客户端Kotlin · ComposeKeyChain mTLS、系统分享、前台同步服务与 MediaStore 归档。

一次传输如何发生

  1. 反向代理校验客户端证书，并覆盖身份头。
  2. 控制面把证书指纹映射为稳定的 DeviceID，并签发一次性 32 字节 会话票据。
  3. 两端按 300 ms 一档并发探测 LAN 与 VPN 候选地址。
  4. 直连成功时完成 mTLS 并传输 49 字节 定长帧；1.2 秒内无人应答则由服务端用 io.Copy 中继同一会话。
  5. 文字与阈值内的文件也可以持久化：SQLite 元数据加一个 blob 目录。

当前限制

  • 记录不会自动过期，目前也没有配额。
  • 端到端 P2P 仍需真实网络回归测试。
  • 客户端自动检查更新暂缓。
  • 仓库尚未声明全局许可证。
状态

版本 0.5.0 系列，仍在开发中。请把部署说明当作可工作的基线，而不是生产保证。

从这里开始

  • 部署控制面，放在你自己的反向代理之后。
  • 选择 Windows 或 Android 客户端。
  • 在编写新客户端之前，先读线上协议。

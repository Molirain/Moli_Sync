Android 客户端是一个面向 Android 8.0 / API 26 及以上版本的 Kotlin 应用。它通过 KeyChain 获取客户端证书，强制 HTTPS，并通过 MediaStore 归档接收的文件。

环境要求

  • Android 8.0 / API 26 或更高。
  • JDK 17+、Android SDK Platform 35 与 Build-Tools 35.0.0。

构建

cd client-android
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug

Windows 下请使用 gradlew.bat。

证书与传输

客户端通过 KeyChain 获取证书与私钥；强制 HTTPS，禁用明文流量与 HTTP 重定向；打包 molisync_ca.crt 时会固定该私有 CA。

能力

  • 系统分享与流式发送。
  • P2P 收发与前台数据同步服务。
  • MediaStore 归档：Pictures/MoliSync 与 Download/MoliSync。
  • 可在运行时调整 5–50 MiB 的 P2P 阈值。

共同行为

15 MiB 阈值、49 字节帧、一次性会话票据与“只有发送者能删除”与 Windows 共用。参见客户端共同行为或完整的 client-android 指南。

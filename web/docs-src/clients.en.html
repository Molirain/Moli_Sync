Both clients speak the same versioned HTTP/WebSocket protocol and use certificates from the operating system's store. The server URL is always HTTPS. Choose a client for its build and connection steps.

Windows

The .NET 8 desktop client is published for win-x64, reads its key from the Windows personal certificate store, and supports NativeAOT.

Build and connect the Windows client →

Android

The Kotlin client targets Android 8.0 / API 26 and newer, gets its identity from KeyChain, and archives downloads through MediaStore.

Build and connect the Android client →

Shared behavior

  • 15 MiB default threshold; above it, P2P only.
  • 49-byte frames and single-use session tickets.
  • Only the sender can delete a record.

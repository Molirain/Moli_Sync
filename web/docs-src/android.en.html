The Android client is a Kotlin app for Android 8.0 / API 26 and newer. It gets its client certificate from KeyChain, requires HTTPS, and archives received files through MediaStore.

Requirements

  • Android 8.0 / API 26 or newer.
  • JDK 17+, Android SDK Platform 35 and Build-Tools 35.0.0.

Build

cd client-android
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug

On Windows, use gradlew.bat.

Certificates and transport

KeyChain provides the client certificate and private key. The client requires HTTPS, disables cleartext traffic and HTTP redirects, and uses a pinned private CA when molisync_ca.crt is packaged.

What you get

  • System share intents and a streaming sender.
  • P2P send and receive plus a foreground sync service.
  • MediaStore archiving: Pictures/MoliSync and Download/MoliSync.
  • Adjustable 5–50 MiB P2P threshold.

Shared behavior

The 15 MiB threshold, 49-byte frames, single-use session tickets and sender-only deletion are shared with Windows. See shared client behavior or the full client-android guide.

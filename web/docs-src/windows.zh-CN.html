Windows 客户端是一个发布为 win-x64 的 .NET 8 桌面应用。它从 Windows 个人证书存储读取证书与私钥，并连接你的 HTTPS 服务器。

环境要求

  • Windows 10 或 11，以及 .NET 8 SDK。
  • 使用 NativeAOT 发布时还需要 Visual C++ 构建工具。

构建与发布

cd client-windows
dotnet build MoliSync.Client.sln -c Release
dotnet test MoliSync.Client.sln -c Release
dotnet publish src/MoliSync.Client/MoliSync.Client.csproj -c Release -r win-x64 -o publish

证书

客户端从 Windows 个人证书存储读取证书与私钥，不会导出到应用文件。若服务端使用私有 CA，请先把 CA 导入一次到“受信任的根证书颁发机构”。

能力

  • 文字、图片、文件三栏，支持 Range 断点续传。
  • 图片缩略图与查看器。
  • P2P 收发、在线设备与 LAN/VPN 地址。
  • 数据目录迁移与开机自启。

运行 publish\MoliSync.Client.exe，填入你的 HTTPS 服务器地址。

共同行为

15 MiB 阈值、49 字节帧、一次性会话票据与“只有发送者能删除”与 Android 共用。参见客户端共同行为或完整的 client-windows 指南。

Privacy

Privacy statement

Last updated 23 October 2026

MoliSync is self-hosted. Your files, text and clipboard history never reach us, and this website has no analytics, no cookies and no third-party requests.

What is collected

Exactly one event per device, the first time it connects to a MoliSync server, and never again afterwards. It contains:

  • an opaque id derived from the deployment id and a salted device key (SHA-256, truncated to 128 bits);
  • the platform (windows, android or other);
  • the server version;
  • a timestamp.

What is never collected

  • no device name, certificate fingerprint, IP address or hardware identifier;
  • no text, file names, file contents, clipboard history or record metadata;
  • no cookies, advertising ids, fingerprinting scripts or analytics SDKs;
  • no account, e-mail address or contact information.

Why it exists

To know how many devices installed MoliSync and which versions are in use. Nothing else.

Where it goes

Your own server sends the event to statistics-api.molirain.com, a Cloudflare Worker backed by D1.

The counter stores only that opaque id, the platform, the version and the timestamp. The id is scoped to a single deployment, so the same device cannot be linked across installations. Only aggregate numbers are ever published.

Cloudflare is the infrastructure provider and may process request metadata such as the connecting IP under its own policies; the counter code itself does not store it.

How to turn it off

Set MOLISYNC_TELEMETRY_ENABLED=false, or leave telemetry.endpoint empty. Sync, P2P and relay keep working exactly the same.

Each server also exposes its own local counters at GET /api/v1/stats; those never leave your deployment.

Your data stays on your side

Text records and files are stored in your SQLite database and blob directory. The project maintainer has no access to them.

Clients keep certificate private keys in the operating system store or Android KeyChain; they are never uploaded.

Third-party requests

Update checks read the public GitHub Releases API. They use a separate HTTP client without your MoliSync certificate, so your device identity is never presented to GitHub; GitHub simply sees a request like any other visitor.

This website is static and self-contained: fonts, styles and scripts are served from this domain only.

Changes and contact

Material changes are recorded here with a new date. Questions or deletion requests: open an issue at github.com/Molirain/Moli_Sync/issues.
